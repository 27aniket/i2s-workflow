I2S Plantation Website
======================

How to view:
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the website in Chrome, Edge, Firefox, or another browser.

All images are stored in the images/ folder and are referenced locally, so the page does not need an internet connection for its images.
To publish online, upload index.html and the images folder to your hosting provider.
